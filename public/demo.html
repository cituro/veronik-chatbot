Site-ul tau, demonstrativ

Aceasta este o pagina de test pentru widget-ul de chat. Bula de chat apare in coltul din dreapta jos.

Despre noi

Acesta este continutul normal al site-ului tau. Widget-ul de chat se suprapune peste pagina, fara sa afecteze restul continutului.

Cum testezi

  1. Deschide panoul de administrare si autentifica-te cu parola din .env (ADMIN_PASSWORD).
  2. Completeaza numele si descrierea afacerii.
  3. Incarca un document (.txt/.pdf/.docx) sau scaneaza un URL real.
  4. Revino aici si intreaba botul ceva legat de continutul incarcat.
